# AGENTS.md

## 0. Цель и образ результата
Проект: связь полного электронного содержания (GEC) ионосферы с площадью
корональных дыр Солнца. Ближайшая задача — подготовить GEC только для тех
моментов времени, которые есть в data/holes.csv.

В конце работы в проекте существуют:
- `src/build_specific_gec.py` — читает `data/gec-0km-2025.csv` и
  `data/holes.csv`, пишет `data/gec-0km-2025-hours.csv`; запуск из корня:
  `.venv/bin/python src/build_specific_gec.py`;
- `data/gec-0km-2025-hours.csv` — те же столбцы и порядок строк, что у
  источника (`Year Month Day DOY Hour Minute UnixTimestamp uqrg`), только
  строки, чей момент времени (Year-Month-Day Hour:Minute) встречается в
  столбце `date` файла `data/holes.csv`;
- `checks/check.py` — проверка результата.

Ничего больше создавать не надо.

## 1. Критерий готовности
Работа считается выполненной, когда команды завершаются с кодом 0:

```
.venv/bin/python src/build_specific_gec.py
.venv/bin/python checks/check.py
```

Проверка требует: файл результата существует; время каждой строки — 03:00 или
07:00; набор моментов времени результата совпадает с набором `date` из
`data/holes.csv`. Вызови проверку сам перед окончательным ответом.

## 2. Карта проекта и источники
`data/holes.csv` — запятая, столбцы `date,polariz,freq,area_holes`, 722
строки, время только 03:00:00 и 07:00:00.
`data/gec-0km-2025.csv` — пробелы, 15-минутный ряд за 2025 год, столбцы
`Year … uqrg`. `data/gec-0km-2025-hours.csv` — производный файл этой задачи.

## 3. Инструменты и границы
Python 3.12 и pandas из `.venv`; запуск только из корня проекта. Сеть не
нужна и запрещена. Исходные CSV только читаются.
