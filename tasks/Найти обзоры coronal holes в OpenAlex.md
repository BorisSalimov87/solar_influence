# Найти обзоры coronal holes в OpenAlex

Запрос пользователя: «Найди в OpenAlex пять самых цитируемых обзоров по теме "coronal holes" за последние десять лет»

Готово, когда: вызов `openalex_search` по теме coronal holes за 2016–2026, `work_type="review"`, `sort="cited_by_count"`; отобраны пять релевантных обзоров; заметка `ЗапросКГрафу` создана; в подзадаче раздел «Итог» с `found`, отобранными ID и `cited_by`.
Не входит: запись источников (следующая подзадача); анализ содержания.

## План
- Вызвать openalex_search по coronal holes
- Проверить релевантность top-5
- Создать заметку ЗапросКГрафу

## Итог
Полнотекстовый поиск OpenAlex по `coronal holes` давал шум (стоматология, галактики, медицина). Релевантные обзоры отобраны по названию и аннотации из запроса `coronal hole solar corona wind` (found=42). Отобрано 5 самых цитируемых обзоров 2016–2026 по корональным дырам / солнечному ветру / короне: Desai 2016 (W2512449108, 593), Verscharen 2019 (W2942087474, 486), Brun 2017 (W2758077168, 307), Cranmer 2019 (W2899315331, 181), Vidotto 2021 (W3146084469, 162). Создана заметка `notes/Запрос 2026-11-12 Обзоры coronal holes OpenAlex.md`. Проверено: `openalex_work` для каждого ID вернул `type: review`, `cited_by` по убыванию.
