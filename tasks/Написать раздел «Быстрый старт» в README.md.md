# Написать раздел «Быстрый старт» в README.md

Готово, когда: `README.md` записан по черновику плана и содержит строки `1.5762 TECU` и `FAIL: 2 hole times missing in GEC`; `grep -n '^## ' README.md` даёт три раздела — «Быстрый старт», «Данные», «Документация»; в `INDEX.md` есть строка про `README.md`.
Не входит: проверка данных и `checks/check.py`; запуск `src/build_specific_gec.py` и `src/plot_gec.py`; правка `AGENTS.md`.

## Итог
`README.md` записан по черновику плана: разделы «Быстрый старт» (четыре команды из корня проекта), «Данные» (три CSV с числом строк, разделителями и пропуском 2025-11-26), «Документация» (ссылки на `INDEX.md`, `AGENTS.md`, `STATUS.md`, `diary.md`, `ontology.yaml`). Явно сказано, что `checks/check.py` красный по известной причине и интерполировать нельзя. В `INDEX.md` добавлена строка про `README.md`. Проверено: `grep -n '^## ' README.md` → 7, 30, 41; `grep -n '1.5762 TECU' README.md` и `grep -n 'FAIL: 2 hole times missing in GEC' README.md` → по одному совпадению; `ls -l` по 15 упомянутым путям → все существуют.
