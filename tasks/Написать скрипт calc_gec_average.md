# Написать скрипт calc_gec_average

Готово, когда: `src/calc_gec_average.py` запускается командой `.venv/bin/python src/calc_gec_average.py data/gec-0km-2025.csv` с кодом 0 и печатает среднее `uqrg` одной строкой.
Не входит: изменение данных, новые зависимости, графики, отчёт.

## Итог
Создан `src/calc_gec_average.py`: единственный аргумент — путь к CSV, чтение с `sep=r"\s+"`, среднее по непустым числовым `uqrg`, вывод одной строкой, коды возврата 0 — успех, 1 — нет файла или колонки, 2 — неверное число аргументов; файлы не пишет. Проверено: `.venv/bin/python src/calc_gec_average.py data/gec-0km-2025.csv` → `Средний GEC (uqrg): 1.5762 TECU`, код 0; коды ошибок 2, 1 и 1 на отсутствии аргумента, файла и колонки `uqrg`.
