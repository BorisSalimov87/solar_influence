# Проверить граф литературы

Запрос пользователя: «Каждая запись — с запросом, которым она получена»

Готово, когда: проверки из раздела «Проверка» плана проходят; концы связей согласованы с `ontology.yaml`; `data/`, `checks/`, `ontology.yaml` не изменены; `STATUS.md` перезаписан, `diary.md` дописан.
Не входит: запуск `checks/check.py` (к литературе не относится).

## План
- Проверить поля и связи заметок
- Сверить концы связей с ontology.yaml
- Перезаписать STATUS.md и дописать diary.md
